
# SauceDemo - Manual Test Cases

## Project Overview
Manual functional testing of the SauceDemo e-commerce
application.

**Application:** https://www.saucedemo.com/

**Testing Type:** Functional Testing

**Test Design Techniques:**
- Positive Testing
- Negative Testing
- Equivalence Partitioning

## Test Cases

| ID | Test Scenario | Expected Result |
|---|---|---|
| TC-001 | Login with valid credentials | User is redirected to the inventory page |
| TC-002 | Login with invalid password | An error message is displayed |
| TC-003 | Login with empty fields | Required field validation is displayed |
| TC-004 | Add a product to the cart | Product appears in the shopping cart |
| TC-005 | Remove a product from the cart | Product is removed from the cart |
| TC-006 | Sort products by price (low to high) | Products are displayed in ascending price order |
| TC-007 | Complete checkout with valid information | Order confirmation page is displayed |
| TC-008 | Checkout with missing required information | A validation error is displayed |
